Practice Question — Mobile Phone
Class Mobile

Create a class Mobile with the following private attributes:

mobileId = int
brand = String
model = String
price = double
rating = double

Create:

Parameterized constructor
Getters and setters for all attributes
Class MyClass

Create a class MyClass with main() method.

Implement the following two static methods:

1. findMobileByBrand
public static Mobile findMobileByBrand(Mobile[] mobiles, String brand)

This method takes an array of Mobile objects and a String brand as input.

It should find the first Mobile object whose brand matches the given brand.

Matching should be case-insensitive.
If found, return that Mobile object.
If no mobile is found, return null.
Main method

If the returned object is not null, print:

Mobile ID
Model
Price

Each on a separate line.

If returned value is null, print:

No mobile found


2. sortMobilesByPrice
public static Mobile[] sortMobilesByPrice(Mobile[] mobiles, double maxPrice)

This method should:

Select only those mobiles whose:
price < maxPrice
AND rating >= 4.0
Sort the selected mobiles in ascending order of price.
If two mobiles have the same price, sort them in descending order of rating.
Return the sorted array.
If no mobile satisfies the conditions, return null.
Main method

If the returned array is not null, print the model name of each mobile.

Otherwise print:

No mobiles found
