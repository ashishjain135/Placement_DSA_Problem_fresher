🏛️ Problem Statement
Create a class KYC with the following private attributes:
panCardNumber (String)
accountIdentificationType (String)
accountIdentification (String)
status (String)
Write a public parameterized constructor, along with getters and setters for all attributes.
Create another class BankAccount with the following private attributes:
accId (String)
accHolderName (String)
accType (String)
occupation (String)
kyc (KYC Object)
Write a public parameterized constructor, along with getters and setters for all attributes.Create a public class Solution with a main method and implement the following two static methods:
1. findKycStatusCountByOccupationParameters: An array of BankAccount objects and a String parameter occupation.
Logic: Calculate and return the total count of bank accounts matching the given occupation (case-insensitive) whose KYC status attribute is exactly "APPROVED" (case-insensitive).
Return Type: int. If no matching accounts are found, return 0.
2. getAccountDetailsByPanParameters: An array of BankAccount objects and a String parameter panCardNumber.
Logic: Search for the bank account that matches the given PAN card number (case-insensitive).
Return Type: BankAccount object. If no record matches the criteria, return null.
📥 Input Format for Main MethodThe program must accept data for 4 bank account records sequentially.For each bank account, data must be provided in the following exact order:
accId
accHolderName
accType
occupation
panCardNumber
accountIdentificationType
accountIdentification
status
The next input line will be the search occupation string.
The final input line will be the search panCardNumber string.

📤 Output Format for Main MethodPrint the numeric count returned by the first method. 
If the count is 0, print: "No accounts found with approved KYC status".
For the second method, 
print the 
accId, 
accHolderName, and 
accType separated by single spaces. 
If the returned object is null, print: "No account found with the given PAN".
